已完成的历史验证：

- 前一整机版本实际进入桌面，Wi-Fi、蓝牙遥控器配对/回连可用。
- AllStream 在电视上 H.264 / HEVC 视频和 HDMI 音频播放。DRM4 格式修复解决黑视频；sw_sync
  使用 /dev/sw_sync 解决绿色闪烁，用户复测确认改善。
